# Mac / iPad 智能体能力路线

2026-11-17。产品目标是用户给出目标后，由 AI 规划、调用明确的工具、检查实际结果并继续；遇到权限、风险或外部提交时交给用户确认。WorkBuddy / OpenClaw 作为体验方向参考，不视为本项目已经实现的能力。

## 平台分工

| 场景 | Mac 上的执行端 Gateway | iPad / iPhone 控制台 |
| --- | --- | --- |
| 任务与规划 | 连接用户配置的模型，返回结构化建议 | 输入目标、展示计划、修改参数、审批 |
| 文件处理 | 在批准的 workspace 内执行固定工具，回传结果 | 导入用户选择的文件；查看明确请求的结果 |
| 浏览器 | 经 allowlist 执行已有受控路径；完整 DOM 控制器尚缺 | 查看结果、提出修改；不能任意控制 Safari 或其他 App |
| 桌面应用 | 系统授权后由 Gateway 执行；完整 Accessibility 交互尚缺 | 不能绕过沙盒操作其他 App；支持它们公开的系统集成需要另行实现 |
| 屏幕观察 | 屏幕录制、Accessibility、自动化授权依具体工具分别申请 | 不能静默读取其他 App 的屏幕或私有数据 |
| 多轮执行 | 需要模型获得明确授权的证据、受限下一步工具和停止条件 | 审批、查看进展；后台持续在线不能作为可靠承诺 |

Mac Catalyst App 当前也是控制台，不是已经内置完整 Gateway 的原生桌面执行器。安装 App、保存连接、探测服务和操作系统授权是不同步骤，不能互相替代。

## 权限怎样申请

- Mac 屏幕录制用于真实截图；辅助功能用于受控窗口/控件读取和交互；Apple Events 自动化授权仅适用于实际使用此路径的目标应用。权限应授予真正执行工具的 Gateway 进程或宿主，而非一律授予控制台。
- 文件优先使用用户选择与固定 workspace；不以“全磁盘访问”为默认入门要求。不能因为得到目录访问就放宽路径逃逸检查。
- iPad 的文件选择、分享、App Intents、URL scheme 和各服务 API 是可行集成方式，但每项都受系统和目标服务约束；当前未完成的集成不提前列为可用工具。
- iPad 里的 127.0.0.1 指 iPad 自己；连接电脑需要可达的 Gateway 地址和可信 WSS。不要要求用户把长期 token 放进链接、二维码 URL 或任务正文。
- 权限拒绝时停在当前动作，给出具体恢复步骤；禁止以模拟成功掩盖失败，也不自动申请更多权限或扩大 allowlist。

## 按效果排序的迭代

1. **先恢复可重复验收**：修复 v0.87 的认证夹具，复核新 SHA 的真实结果包，不仅看 Actions 颜色。
2. **任务入口易用**：主入口聚焦 AI 计划，明确当前计划来源；规则预览、演练和工程诊断使用次级入口。Mac 窄窗口、iPad 分屏与大字体采用实际宽度适配，编辑状态由父视图拥有。
3. **连接能完成**：保存连接、测试可达、核对实际执行能力、说明缺失权限。能力检测不等于授权，不能用绿色就绪提示代替系统许可或用户审批。
4. **模型真正用上证据**：由用户明确选择有界证据加入下一次规划，限制大小、类型和身份；防止文件/网页内容成为系统指令，不自动读取任意路径。先覆盖一个可验收的读证据→计划→审批→执行→复核闭环。
5. **工具有实际作用**：优先补齐文件/文本处理与浏览器结构化读取，再推进受控 DOM 和 Accessibility 操作；逐个工具补真实结果、失败分类、取消含义与负向回归。新增 action/artifact 时同步全链路合同。
6. **可持续多轮**：持久化任务元数据与经过审计的进度；凭据、receipt 和未应用的敏感正文隔离。保持次数/时间/费用预算、单次发送、幂等和显式停止；真实执行不能依靠 iPad 长驻后台。
7. **发布门槛**：真实模型任务基准、用户授权桌面 E2E、Mac/iPad 实际操作、大字体/键盘/VoiceOver/断线恢复、隐私、图标、签名与分发验证。只有编译通过不能称为发布级。

## 当前证据的限度

现有模型 HTTP smoke 使用小型本机服务夹具验证真实网络与合同，不证明真实模型推理质量。模拟、dry-run、收到 Live 事件、真实动作成功和人工验收应分别记录。生产签名和分发需要用户实际账号/证书及渠道选择，不能伪造。
