# v0.58 / Shell Allowlist Evidence Accuracy Shell 白名单证据准确性

提交信息：`v0.58: 修复 Shell allowlist 检查证据`

## 版本分配依据

v0.51 引入 Shell 策略诊断，v0.54/v0.57 将诊断汇入 iPad/mac 策略看板和 Operator Strip。当前 Gateway 在 Shell disabled 的 dry-run 分支会在真正执行 binary allowlist 查询前短路，却输出 `binaryAllowlistChecked=true`，导致复核 UI 误报证据。本轮修正该语义，不扩大 Shell 权限。

## 目标

- Shell disabled/dry-run 时 `binaryAllowlistChecked=false`。
- Shell enabled 且进入 allowlist 判断时保持 `binaryAllowlistChecked=true`。
- simulator、direct/WebSocket smoke、XCTest、LogicSmoke 与文档对齐。
- iPhone/iPad/mac 复核继续只展示固定 metadata，不读取 payload。

## 非目标

- 不改变 Shell allowlist 匹配规则、执行权限、action/schema/artifact/event。
- 不执行自然语言命令，不展示 raw command、stdout/stderr、cwd/path、token 或 `toolArguments`。
- 不改用户 Xcode 本地工程设置。

## 当前架构依据

- `Tools/claw-gateway-server.mjs` 的 `shellPolicyDiagnostics()` 集中派生 Shell 策略证据。
- `ClawGatewaySimulator.shellCommandSafetyMetadata()` 生成手机端模拟 fixture。
- `ClawGatewayShellCommandSafetyReviewSummary` 和既有 Shell review row 消费该布尔值；v0.54/v0.57 的 Policy Board / Operator Strip 会继续向上汇总。
- direct/WebSocket smoke 已分别覆盖 dry-run 和 allowlist-enabled 路径。

## 风险和禁止项

- 风险：错误地把 allowlist-enabled 分支改为 `false` 会掩盖真实策略检查；测试必须保留其 `true` 断言。
- 风险：该字段只表达是否执行检查，不表达 binary 名称或 allowlist 内容。
- 禁止本地编译、Gateway smoke、Swift logic smoke 或 `node --check`；禁止删除断言、读取 payload、扩大 Shell 权限或混入 Xcode 用户改动。
