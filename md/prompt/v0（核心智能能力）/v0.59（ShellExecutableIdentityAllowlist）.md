# v0.59 / Shell Executable Identity Allowlist Shell 可执行文件身份白名单

提交信息：`v0.59: 阻断 Shell 同名路径绕过`

## 版本分配依据

v0.51 引入 Shell 策略诊断，v0.58 修正 allowlist 检查证据。当前 Gateway 仍只用 `path.basename(parsed.command)` 查询 `CLAW_SHELL_ALLOWLIST`，命中后却执行原始 `parsed.command`；因此 allowlist 包含 `pwd` 时，`/tmp/untrusted/pwd`、`./pwd` 等路径形式可借同名 basename 绕过 binary identity 边界。本轮优先修复该真实执行权限问题。

## 背景与目标

- `CLAW_SHELL_ALLOWLIST` 的裸 binary 名只能授权同名裸 command token。
- 含 `/` 或 `\\` 的 command token 必须在执行前被策略阻断，即使 basename 在 allowlist 中。
- 路径阻断沿用现有 `shell-policy-blocked` / `allowlist-blocked` 安全结果，不暴露 raw path 或 command。
- 阻断 metadata 必须保持 `allowlistMatched=false`、`executionAttempted=false`、`executed=false`、`binaryAllowlistChecked=true`。
- 正常裸命令 `pwd` 的 allowlist-enabled 真执行路径必须继续通过。

## 非目标

- 不新增完整路径 allowlist、命令模板、三阶段审批 UI 或自然语言 Shell。
- 不改变 action/schema/artifact/event kind，不扩大 Shell 权限。
- 不处理 Browser redirect allowlist、Mission Run session affinity 或其他后续候选。
- 不展示 raw command、binary/args、cwd/path、stdout/stderr、token、header 或 `toolArguments`。
- 不修改用户已有 Xcode 工程和 scheme 改动。

## 当前架构依据

- `Tools/claw-gateway-server.mjs` 的 `runShellAction()` 负责解析结构化 `toolArguments.shellCommand`、检查 Shell 策略与执行命令。
- 当前实现用 `path.basename(parsed.command)` 做 allowlist 查询，再把原始 `parsed.command` 传给 `runProcess()`。
- `shellCommandSafetyMetadata()` 和 `shellPolicyDiagnostics()` 已能表达 allowlist 阻断，无需新增 metadata key 或枚举。
- direct smoke 已覆盖 allowlist-enabled 的 `pwd` 真执行路径；WebSocket smoke 已覆盖 Shell 策略阻断和 metadata。

## 实现步骤

1. 在 Gateway Shell 执行路径增加清晰、可复用的 executable identity 校验：仅接受不含正反路径分隔符的裸 command token。
2. allowlist 判断必须同时要求 identity 合法且裸 binary 精确命中；任何路径形式在 `runProcess()` 前返回现有策略阻断结果。
3. 保持阻断事件、retry 行为和 metadata-only 安全边界；不得把路径或命令加入 artifact event metadata。
4. direct smoke 增加同名路径绕过回归，构造可观察副作用并断言未执行；保留正常 `pwd` 成功断言。
5. WebSocket smoke 增加路径形式阻断断言，核对 action failure 与 Shell Safety metadata。
6. 更新 README、协议、flow/flowchart、test 和 update_log。

## 验收标准

- allowlist 为 `pwd` 时，`pwd` 仍可执行。
- `/tmp/untrusted/pwd`、`./pwd` 或含反斜杠的同名路径不会执行，也不会产生测试副作用。
- 路径阻断使用固定安全 metadata，明确 allowlist 已检查但未命中且执行未开始。
- 最新 `origin/main` CI run 对应本轮 commit，artifact manifest/JUnit/log/xcresult 全部通过。

## 风险和禁止项

- 风险：只比较 basename 会保留绕过；必须在 allowlist 命中前验证原始 command token 身份。
- 风险：误伤正常裸命令会破坏已有 Shell 真执行能力；测试必须保留成功路径。
- 风险：测试若只检查事件而不检查副作用，无法证明命令未执行；direct smoke 必须加入副作用断言。
- 禁止本地编译或 smoke、删除既有断言、放宽 allowlist、增加任意路径执行、读取 artifact payload 进入手机 UI，或混入 Xcode 用户改动。
