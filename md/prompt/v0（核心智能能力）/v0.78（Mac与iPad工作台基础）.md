# v0.78：Mac 与 iPad 工作台基础

日期：2026-09-26。版本依据：v0.77 基线修复后的下一小轮，不等同 v1.0 发布。用户明确要求单 agent，自身顺序承担规划、实现和 artifact 复判，不创建子 agent。

## 前置验收
可以在等待时准备独立平台改动，但提交前，v0.77 最新 origin/main run 必须成功且已下载 artifact，核对 manifest/JUnit/主日志/xcresult；不以 step 的 continue-on-error conclusion 代替最终 outcome。

## 背景与架构依据
当前 App target 只有 iPhone/iPad，未启用 Catalyst；iPad 的 plist 方向仍继承单一竖屏。`ContentView.swift` 含 8,391 行，PhoneAgentView 只按 horizontalSizeClass 决定双栏；各布局各自持有 reviewFocus，窗口转换会丢失 UI 聚焦。

## 目标
1. 为现有 App/Test target 开启 Mac Catalyst，提交共享 scheme；保留本机未提交的签名 team/scheme 配置，不夹带旧提示词。
2. 修复 iPad 四方向支持；把工作台抽取为独立 SwiftUI 文件，以实际宽度和 Dynamic Type 决定单/双栏，父视图统一持有 reviewFocus。
3. Mac/宽屏 iPad 提供侧栏导航，默认进入任务工作台；窄窗口保留所有入口与审核能力。遵守现有 Store 显式审批/发送边界，不让切换布局或快捷键自动发送。
4. CI 增加 Release Mac Catalyst build 和 iPad Simulator XCTest，保留 iPhone、Swift、Gateway 全回归。新平台结果进入 manifest/JUnit/失败门槛和小体积 artifact。

## 非目标
不把 Catalyst 宣称原生 AppKit 重写；不更换 Gateway 协议、action/artifact 或权限；不引入第三方库、模型权重、不绕过审批，不以增加面板假装增加智能。

## 实现与关键文件
`Claw/Views/ContentView.swift`、新的工作台/布局策略文件、`Claw.xcodeproj/project.pbxproj`、共享 scheme、`ClawTests/ClawTests.swift`、`Tools/LogicSmoke.swift`、`.github/workflows/ci-results.yml`。布局策略应可独立测试宽度边界、无效宽度和辅助大字体；跨窗口切换只重排，任务/审批状态保留。
