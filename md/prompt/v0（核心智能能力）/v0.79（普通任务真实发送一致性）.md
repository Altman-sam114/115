# v0.79：普通任务真实发送一致性

日期：2026-09-27。Agent X 单实例顺序执行规划、实现、验收，不创建子 agent。版本依据：v0.78 平台基础之后的真实执行链路修复。前置为 v0.78 最新 main 云端 artifact 验收通过；可提前分析，不提前宣称通过。

## 背景与架构依据
Store.beginGatewaySession 为普通任务先生成 candidate 的 JSON，再把 task.status 改为 sent；Gateway ordinary preflight 只接受 sent。现有 Mock transport 只解码而不检查状态，因此模拟测试掩盖真实发送错误。普通 approveTask 还允许重新审批 sent 任务并重建会话；Bridge 面板发送按钮只调用同步准备入口，live 模式未启动网络 transport。

## 目标与非目标
修正普通发送 wire 状态和 UI live 发送入口，阻止已发送任务重新审批/重复发送。续接 frozen readyToSend 合同保持不变；不修改 Gateway action/schema、模型服务、参数编辑或自动重连策略，不绕过审批。

## 实现步骤与关键文件
1. ClawStore.swift 普通分支仅将发送副本序列化为 sent，保持 task identity/actions；拒绝普通 sent/blocked 审批。
2. ContentView.swift Bridge 显式发送按所选模式调用真实 async transport 或模拟入口，捕获精确 task ID；生命周期不得隐式联网。
3. ClawTests.swift 增加严格普通 wire 状态 transport fake、已发送重新审批/重复发送无副作用和未审批零调用测试；LogicSmoke 保留普通发送与续接回归。
4. 同步 README、协议、flow/flowchart、test、update_log 与 CI 产品版本。

## 风险与禁止项

补充范围：Mission 主按钮复用拆分后的规划/审批/dispatch preparation，live 模式显式调用 async transport；模拟入口保留。approval 必须匹配 Mission task ID，异步结果仅更新仍匹配的 Mission。新增云端测试覆盖审批前零请求、审批后一次请求及 completed、重复点击和排队任务被替换后不审批新任务。
UI task 切换需绑定点击时 task ID；重复点击由 Store sent guard 拒绝。Gateway 进程重启重放与无确认网络重连仍为发布缺口，本轮不得扩展协议以隐式规避。不得修改 aitrans 或用户 signing/xcuserdata，不得本地编译、运行 smoke 或创建模拟器。
