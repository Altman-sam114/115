## 目标与非目标

- 启动后有界采集真实模拟器帧；必须同时识别到 Claw 品牌和正文中的 Mission Run 才接受。只导航栏、状态栏、白屏或不可读文件均不通过。
- 最多 15 帧，帧间 2 秒，只保留最后一帧；未就绪可继续等，读取/OCR 错误直接失败，避免无限延迟或大量图片。步骤本身保留 15 分钟上限，validator 编译/自测步骤 3 分钟上限。
- OCR 原文可能包含任务输入，永不进入日志/JSON；只输出固定就绪代码。此工具仅 CI 视觉证据检查，不接入 App、模型规划或 Gateway。
- 不修改产品 Swift/JS、Xcode project、签名、权限、envelope、handler 或业务测试断言，不创建本机模拟器，不修改 aitrans，不纳入 v0.83 草稿。

## 风险与停止

- OCR 是固定首屏的就绪信号，不是完整 UI 可用性或发布认证；布局标题改动须同步测试合同，不允许把 marker 注入假页面绕过。
- 云端 Simulator cold boot/data migration 与真实产品启动应分开，不能把 runner 迁移耗时称作 App 性能。当前证据仍不足以判断白屏根因。
- 同因连续 CI 失败、三轮同一阻塞、两轮无有效 diff、权限/账号/密钥/付费或人工产品决策、归属不明改动、用户停止，按 AGENTS 停止。
