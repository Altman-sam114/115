## 3. 目标和非目标

目标：

1. 两种布局共享“输入 -> 当前 Mission / 单一 Smart Rail -> 计划与审批、证据复核、会话事件、权限与连接”的按需详情入口，不再默认堆叠全部看板。
2. Mission 概况始终保留当前阶段、风险/审批/结果计数、明确模拟或 live 来源、既有主动作、continuation 参数编辑和固定失败提示；不能把审批、失败或待填写参数藏进高级诊断。
3. 高级 metadata 看板显式展开才构建，保留所有现有安全/证据/projector 功能；普通复核保留 scope/stale 提示、优先复核入口和详细 rows。
4. 详情选项、高级展开状态和 scoped focus 在父 View 持有；窗口跨越 900pt 和辅助大字体切换时保留，不触发网络、审批或发送。用户显式聚焦复核时转到复核区，旧 focus 仍由现有 summary fail closed。
5. 用固定类型化详情枚举和轻量 presentation state 约束 UI；控件至少 44pt、长文本可换行、可访问性明确只导航。当前关键词规划明确标为规则预览，不冒充 LLM。

非目标：不接模型、不增加权限/handler/action/artifact/schema、不改普通/continuation 审批与参数、不做真实桌面动作、自动发送或重试、不修改 Xcode project/签名/依赖、不重写整个 ContentView 或 Store。

## 4. 实现步骤和关键文件

实施前复审补充：既有 continuation editor 把四个输入字段保存在子 View 的 `@State`，跨 compact/workbench 分支时会重建。除下述详情导航 state 外，父级还需保存独立、非 Codable、仅进程内的 editor input state；按 draftID/parent task/session/editor kind 绑定，首次进入新 scope 才载入，布局重建不能覆盖未应用输入，Store 参数变化仍显式刷新。错误 scope 的旧输入不得在新编辑器闪现；此 state 不进入 summary、checkpoint、envelope、日志或 artifact，也不自动调用应用参数 API。补云端文件/提取输入、布局切换、新 scope/不可用清空与 Store 刷新的回归。

应用参数按钮还需比较渲染 summary 与当前 summary，并要求 editor 绑定同 scope 且当前可编辑；不匹配直接拒绝，防止重排后的旧按钮用旧输入改写新草稿。此 UI 防护不替代 Store 的 receipt、父 scope、审批/冻结和 typed validator 闸门。

Live health 继续复用现有 health strip，主 Mission 仅展示其状态/失败说明，探测、readiness、checkpoint 和完整配对详情放到连接区。health 的既有 review-focus metadata 同步仍保留（不联网），不得因详情折叠破坏 probe/readiness stale guard。主动作仅在 Mission 概况出现，不在复核 dock 再放一份。

结果来源徽标只从匹配当前 task/session 的固定 channel 和 scoped Gateway ack 派生：无会话、模拟、Live 未确认、Live 事件已接收和未知来源均为固定文案；不回显任意 channel，也不把 live ack 写成真实动作成功。当前发送设置另列，不得在用户切换设置后把已有模拟证据改标为 live。

1. `Claw/Core/ClawWorkspaceLayout.swift`：加入固定详情枚举及仅用于选区/高级展开的 presentation state，默认计划与审批；无 Store、任务、网络或持久化依赖。
2. `Claw/Views/PhoneAgentView.swift`：父级保存 presentation/editor state，传递同一个 scoped focus Binding；focus 的本地 onChange 只切换到复核区，不新增隐式任务动作。健康条原有 onAppear/onChange 仅同步本地 probe/readiness scope，不联网。
3. `PhoneAgentCompactLayout.swift` / `PhoneAgentWorkbenchLayout.swift`：复用同一个详情 selector/content，原宽度算法及辅助大字体回退不变。
4. `ContentView.swift`：将主 Mission 精简为概况/主动作/continuation/计数，现有复核组件统一放入共享复核 dock，metadata 看板收拢到显式高级 disclosure。将 envelope 原文改为用户显式展开，不改变内容/编码或派发。
5. 保留全部既有 projector、View、dispatcher 和 Store API；优先按复核职责组合，不引入新的业务 VM 或同义看板。新小 View 放入已有工程收录的源码，避免碰用户 project diff。
6. `ClawTests/ClawTests.swift` / `Tools/LogicSmoke.swift`：固定默认/切换/复核导航/高级展开、布局边界和无业务副作用回归；有需要时在云端 XCTest 添加小型 UIKit hosting 渲染附件，说明仅为布局证据，不替代真实用户交互。
7. 仅将 workflow iteration 更新为 v0.83；保留全量 iOS/Catalyst Release、iPhone/iPad XCTest、fixture/Gateway 回归、截图与 artifact 门槛。
