## 背景和架构依据

- `ClawMobileBridge.toolArguments` 仍自动填充示例 HTML、占位文件正文、默认 `pwd`、根据自然语言拼出的桌面正文和 `command+k,return`；用户审批的并非其真正想执行的最终动作。
- Bridge 把本机解析、审计和系统能力步骤也发送给不支持这些 handler 的 Node Gateway，不能把这些步骤宣称已在手机或桌面真实执行。
- 普通任务审批只有 status，没有最终 task/profile 摘要绑定；未来参数编辑必须使旧审批失效。
- Gateway 的文件 handler 缺正文时会把 instruction 写入文件；desktopPasteText 会回退到 inputPreview。这两处需要移除自然语言作为可执行输入的兜底。
- v0.83 父 View 已负责布局生命周期；参数编辑应作为父级 sheet，而不是在可重建的 compact/workbench 子树里持有未应用输入。

## 目标

1. 规则规划保留为预览；Gateway task 只承载桌面动作、受控消息草稿和明确阻断项，本机准备/系统能力不伪装成远端执行；无远端动作的任务不可发送。
2. 删除危险占位参数。搜索目标、观察目标、提取目标和安全 workspace 路径可以是待审建议；Shell、写入正文、桌面输入/快捷键、收件人与消息正文必须显式填写，不从自然语言猜出执行文本。
3. 新建独立 Core 参数合同：固定字段、UTF-8 上限、workspace 相对路径、无 credentials 的 http(s) URL、固定安全开关和支持 kind；错误提示为固定文案，不回显输入。
4. 共享最终参数列表与编辑 sheet 支持浏览器、文件、Shell、桌面输入、提取、消息/邮件草稿。原始参数只在用户明确打开的编辑器/现有 envelope 内显示，不进入 metadata、checkpoint、日志或 accessibility 摘要；重排不丢未应用输入。
5. Apply 绑定最新未发送普通 task/action 的完整快照；stale、sent、历史任务、continuation、blocked 一律拒绝。有效编辑只更新该 action，撤销普通审批、恢复待审批，不 queue/联网/自动发送。
6. 普通审批以最终 task 与 profile 的短生命周期内存摘要绑定；真实发送前重复校验参数、审批和 profile，失败零 transport、零 session/event/artifact。模拟仍允许未完成参数的明确演练，但不能授权带缺口的真实执行。
7. Gateway 移除文件正文与桌面 inputPreview 兜底；缺结构化文件输入时在写入前返回固定脱敏 action-bound 审计失败。fixture 和 direct/WebSocket smoke 覆盖同一合同及无副作用。

## 非目标与禁止项

不接模型/账号/付费服务，不新增 schema/action/event/artifact，不扩大 Shell、桌面、浏览器权限，不实现最终发送，不改变 continuation receipt/freeze 合同，不做全面 Store/Models 重写，不修改 aitrans。不删除测试断言来制造通过；变更旧断言必须针对明确废除的危险默认值或本机步骤误路由，换成更强的边界断言。

## 实现步骤与关键文件

1. `Claw/Core/ClawTaskArguments.swift`：固定参数模型/验证、编辑输入和上下文；纯值、可测试，无网络和持久化。新增源码在 project 中注册，精确分段暂存，不能把用户 DEVELOPMENT_TEAM 修改提交。
2. `Claw/Services/ClawStore.swift`：Bridge 去占位/区分本机准备，普通审批摘要记录，参数编辑 API，beginGatewaySession 的真实发送闸门。Mission 的真实派发不能在闸门拒绝后误显示已发送或陷入无会话等待。
3. `Claw/Views/ClawTaskArgumentsEditor.swift` 及 PhoneAgentView/layout/ContentView：父级 sheet 与共享参数列表；固定类型字段，44pt、换行、明确应用会撤销旧审批；关闭 sheet 不应用。主 Mission 显示参数缺口和进入计划/参数区的入口，不能把必要输入埋到高级诊断。
4. `Tools/claw-gateway-server.mjs`：文件缺必需结构化参数时无 write fallback；desktopPasteText 只允许 toolArguments 来源。保留既有路径逃逸、symlink、allowlist、最终提交、审计与失败状态。
5. `Tools/ClawGatewayEventFixture.swift`、direct/WebSocket smoke、XCTest、LogicSmoke：补实际负向/正向矩阵，不用 mock 成功代替真实桌面验收。
6. 同步 README、协议、flow/flowchart、test、release-readiness、update_log、prompt 索引；workflow 只更新 iteration 为 v0.84，保留全部云端检查。

实施前静态复审补充：既有两个英文 Mission scope 夹具此前只因本机步骤误路由才创建假会话；去掉本机步骤后应补 browser/report 等明确英文规则意图，而不能把这些回归换成更容易通过的中文任务。仍标注规则规划、没有模型推理。新增共享 `Tools/claw-final-input-smoke-fixture.mjs`，direct/WebSocket 使用同一缺输入/无自然语言兜底/合法后续写入矩阵，workflow 同步增加该模块语法检查，不缩减平台矩阵。保留桌面显式正文的首尾空白，不回退 inputPreview。连接字段或运行时 token 的任何编辑撤销普通审批；token 与已保存指纹不匹配时真实发送先拒绝。

## 测试与验收

- Bridge 无示例 HTML、猜测 Shell/正文/快捷键；只有本机步骤时 blocked；已明确不支持的平台请求仍 blocked；远端搜索不再带假网页证据。
- 各 typed 编辑生成固定 keys/安全开关。缺必需输入、未知字段、过长 UTF-8、绝对/逃逸路径、URL credentials/非法协议等拒绝且无原文泄露。
- 正向编辑只改当前 action，ID/父任务和其他动作不变，旧审批失效；编辑未应用/无效/stale/换任务/sent/continuation 均无业务副作用；sheet 生命周期与布局 state 分离。
- 真实发送缺参数或审批/profile 不匹配时零 transport/session/event；有效参数经新审批只发送一次，wire 与已审最终参数完全一致；模拟不能绕过真实闸门，v0.82 终态/失败隔离与 continuation 断言保留。
- Gateway direct/WebSocket 覆盖缺 path/text/错误类型、自然语言 marker 不落盘或成为粘贴内容、固定审计失败和后续合法动作继续；显式结构化写入仍落盘且内容精确。
- 本地仅 `git status`、`git diff --check`、YAML/plist 解析、文本/diff 复核。禁止本地 compiler/build/xcodebuild/XCTest/LogicSmoke/fixture/Gateway smoke/node --check/模拟器。
