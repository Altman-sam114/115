## 背景、目标和边界

当前 PhoneAgentPlanner 仅关键词规则，LocalClawModel 是 placeholder。Mac/iPad 工作台必须有真实模型请求入口，不能把规则、fixture 或模拟当模型推理。本轮接入 Gateway 同机、用户已安装并明确配置的 Ollama `/api/chat`；不下载模型，不预设模型名，不使用付费 API 或读取其他项目凭据。官方依据：`https://docs.ollama.com/api/chat` 与 `https://docs.ollama.com/capabilities/structured-outputs`，使用非流式 JSON schema format、显式输出上限与实际 token 计数。

目标：
1. 独立 authenticated HTTP `POST /claw/planning`，协议 `claw.gateway.planning.v1`，只接受 command/nonce，不是执行 envelope。必须配置非空 Gateway token；模型 endpoint 只能是无账号密码/query/fragment 的 loopback HTTP `/api/chat`，模型名显式配置，缺配置零推理请求。
2. 仅发送本次用户文本和固定动作 schema，不上传屏幕、文件、artifact、会话或 receipt。单次请求，无自动重试、redirect 或模型下载；有界输入/输出、超时、取消、并发容量和固定脱敏错误。规划路径不进入 workspace/replay/session/event/artifact/handler。
3. 模型只能提出最多八个已支持 action 的 kind/goal/typed inputs；不能指定审批、风险、权限、安全开关、envelope 或 loop。Node/Swift 两侧拒绝未知字段、种类、越界输入和危险路径/URL；固定安全参数由客户端生成。缺必需正文可保留空白，之后真实发送必须由 v0.84 gate 拦截，禁止猜测占位正文。
4. 模型计划有明确 source；每步携带已校验 typed action，不再靠 model title/target 字符串反推 kind。Bridge 派生既有 allowlist、审批、风险和敏感标记。用户另行生成任务、复核最终参数、审批、显式发送；模型请求成功不创建 task/session/event/artifact，不自动执行。
5. 共享 Command/Plan 主路径显示规则/模型来源、请求中/失败/取消与实际 token 用量；至少 44pt，VoiceOver 明确数据去向及不执行。请求绑定 command/profile/plan/task/session revision，编辑、切换任务、规则重规划或取消后旧结果不能覆盖新上下文。Mission 显式启动保留同 command 的有效模型计划，不暗中改回关键词计划。

非目标：本轮不实现视觉模型、多轮自主工具调用、真实桌面授权 E2E、配对/TLS/凭据持久化或签名发布；不声称 fixture 证明模型质量，不运行本地服务/编译/测试，不新增电脑 action/artifact 或扩大执行权限。

## 实现步骤与关键文件

- 新 Core 合同文件：固定 DTO/typed input -> 安全 toolArguments、nonce/响应校验、固定来源与错误文案；PhoneAgentStep/Plan 增加 optional typed proposal/source，规则默认不变。
- 新独立 Services transport：从已保存 ws/wss Gateway origin 推导固定 HTTP(S) 路径，header-only token，拒绝 redirect，ephemeral session、有界读取、timeout/cancel；ClawStore 维护短生命周期规划 operation 和 scope guard。
- Bridge 优先使用经过合同验证的 typed proposal，仍保留原规则路径；queue 与 Mission 检查当前 command/source，旧模型计划 fail closed。
- 新 Node planning 模块，Gateway HTTP 路由先认证与严格 JSON，再访问已配置 Ollama；固定 schema 限制输出，验证后只返回 proposal/用量，所有错误固定脱敏；普通 WebSocket/readiness/continuation 不变。
- 新 cloud-only HTTP provider fixture smoke 覆盖真实请求边界；Swift XCTest/LogicSmoke 覆盖 source/typed mapping、缺参阻断、失败/取消/stale 与无执行副作用。project 注册新增文件，精确暂存，排除用户 signing diff。
- workflow 增加新模块语法与 planning smoke，纳入 manifest/JUnit/最终 gate，不减少已有平台与 Gateway 矩阵。同步 README、协议、flow/flowchart、test、release readiness、update_log、prompt 索引。
