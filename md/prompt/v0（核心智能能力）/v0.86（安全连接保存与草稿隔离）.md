## 版本分配依据与背景

v0.85 最新 main `edab5a9a6feb6598e9122122fe549951f02c1d6b` / run `39841407261` attempt `1` 已通过单实例 C 阶段：下载精确 artifact `claw-ci-v0.85-main-edab5a9a6feb-run39841407261-attempt1`（1,973,076 bytes / 解压 4.7 MiB），manifest/JUnit/摘要/实际日志一致，15 项检查全部成功，iPhone/iPad 各 150 项 XCTest 零失败，双平台 Release、LogicSmoke、fixture、Gateway 和生产 Swift 模型 HTTP client + 21 次有界 provider fixture 请求通过。四个 xcresult Info/root 数据存在；已打开两张实际非白屏 PNG，与 iPhone 第 1 帧/iPad 第 2 帧 readiness JSON 一致。本机无 xcresulttool，未独立解码二进制；Catalyst runner Metal 路径警告保留。上一轮是有效进展，不是发布完成或真实模型质量证明。

源码审计发现“保存网关配置”只改内存，重启遗失 token，并仍带硬编码私网地址。连接表单与运行时字段混用，旧 probe/readiness 路径可能在用户编辑地址/凭据后用旧 endpoint 发送新 token。下一轮必须先保护真实模型与任务入口的连接身份，再继续模型能力，不增加看板。

## 目标、非目标与架构依据

1. 新增受限 endpoint/token 配置合同及注入式存储。生产 App 仅在用户显式保存时，将 endpoint 和 token 作为一条原子 Keychain record 发布；固定 service/account、WhenUnlockedThisDeviceOnly、不 iCloud 同步、不 UserDefaults/普通文件，不保存任务/审批/receipt。
2. 地址只接受 WSS 或精确 loopback WS；拒绝 userinfo/query/fragment、空 host、控制字符、反斜线、非法端口和超限。token 限有界可见 ASCII，拒绝 header 注入。共享校验用于模型/live/probe/readiness 与生产 WebSocket transport，不只保护保存按钮。
3. 保存失败保留原已应用 pair，草稿不被当作已保存。读取失败/损坏固定脱敏显示；启动读取只恢复连接配置，不联网、不创建 task/session/event/artifact、不恢复 Mission/审批/receipt。默认测试与 preview 使用 no-op 存储，不触碰生产 Keychain。
4. 显式保存、重新读取、还原内存草稿、确认清除入口，展示保存与未应用状态。清除成功才移除运行时 pair，并撤销旧审批/模型/续接授权；失败保持原配置，不冒充删除远端 token。共享连接 view 用于 Mac/iPad/iPhone，44pt/VoiceOver；不回显 token、header、任意错误原文。
5. 地址或 token 草稿不匹配当前已应用 pair 时，模型、probe、readiness、普通 live 和 continuation live 均不调用 transport。普通/续接发送在创建 session 前拒绝 dirty pair。编辑切回、保存/读取/清除仍使旧异步结果和授权过期；不能仅凭短指纹决定完整凭据相等。

依据：`ClawStore` 的 gatewayURL/gatewayToken 为 UI 草稿、clawGatewayProfile 为应用配置；v0.85 模型操作 generation/binding、v0.84 普通审批摘要、现有 continuation frozen receipt 和 v0.73/v0.75 独立控制面继续保留。`aitrans/safety/CreditWalletRepository.swift` 只读参考原子 SecItemUpdate/Add 和设备独占策略，不修改 aitrans 或读取其凭据。

非目标：不增加 Gateway action/artifact/schema，不实现配对/撤销远端 token/TLS 证书安装/后台连接/自动任务恢复，不自动选择或下载模型，不把 Keychain 当成设备信任认证，不改用户签名或历史 prompt，不运行本地编译或业务测试。

## 实现步骤与关键文件

- 新 Core 配置合同、固定状态文案；Services Keychain adapter、注入式 fake/no-op。
- `ClawStore` 注入存储、启动只读恢复、明确 save/reload/revert/clear；完整已应用凭据的内存绑定与统一 dirty guard，异步 stale/generation 和审批失效仍 fail closed。
- `ClawApp` 显式启用生产 Keychain；共享连接配置 view 替代旧假保存按钮，清除/覆盖草稿有确认提示。
- 共享 endpoint/token validator 进入 planning/live/probe/readiness 与生产 transport；现有负向测试保留，原来非法 query/明文远端的成功夹具改为合法 WSS 路径，另加专门拒绝矩阵，不能删除安全断言。
- 新 XCTest 覆盖合同、存储失败、重启隔离、dirty 全入口、旧授权/异步结果和真实隔离 namespace Keychain 的 create/update/load/delete/属性；LogicSmoke 用注入 fake 回归，不碰本机 Keychain。project/workflow 注册新增源码，保留原全矩阵。
- 同步 README、协议、flow/flowchart、test、release-readiness、update_log、prompt 索引，记录上一轮真实验收及剩余发布缺口。
