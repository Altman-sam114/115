## 目标与非目标

- 目标：当前 Live Mission 的用户显式选择 -> 认证 HTTP 结果请求 -> 只返回该 task/artifact 的有界不可变文本快照 -> plain Text sheet；显示来源、容量与非执行边界。
- 非目标：任意文件下载、URL/file reference 打开、图片/二进制预览、HTML/Markdown 执行、模型自动读证据、跨重启恢复、后台读取、自动重试/审批/发送、配对/TLS 安装、真实桌面 E2E、签名分发。
- 仅支持 fileDiff、commandOutput、browserTrace、messageDraft。auditLog、agentTrace、accessibilityTree、screenshot 不开放；不宣称 isRedacted 是内容脱敏保证。

## 当前架构依据与关键文件

- Node Gateway `writeArtifact` 已掌握真正的序列化结果；在写入成功后注册内存快照，无需读取用户路径，避免 file reference 与路径/符号链接攻击。
- `ClawGatewayArtifact` 保留原协议字段；客户端按当前 Mission/session 与 Live 来源筛选，绑定配置 revision 和精确 artifact。独立控制面不进入 task/replay/workspace/handler pipeline。
- 新增 Core 合同、HTTP transport、共享结果 sheet 与 Gateway registry/route/smoke；Store 拥有请求、取消、generation/stale guard。保持现有 Mission 复核索引 metadata-only 语义。
- `aitrans` 只读参考 bounded attachment / stale callback 原则，不修改它、不读取其凭据或复制依赖/权重。

## 实现步骤

1. 独立 `claw.gateway.artifact-preview.v1` POST 控制面，固定路径 `/claw/artifacts/preview`，必须配置并验证 Gateway token，header-only。strict UTF-8/JSON、duplicate key、exact fields、nonce/UUID、方法/header/容量/时限校验；固定脱敏错误，no-store/no redirect。
2. Gateway 只在成功 writeArtifact 后按 taskID/artifactID 注册四类 UTF-8 快照，最大 32 KiB/项、64 项/进程、10 分钟 TTL；超大/未知不注册、不截断、不从磁盘重新读取。请求不允许 reference/path/URL/任意可执行参数；缺失/过期/错 task 同一固定 not-available。请求没有电脑动作、文件/业务 artifact 写入或 receipt 副作用。
3. Swift 严格验证 response nonce/task/artifact/kind/mediaType/byteCount 和 effects=false，实际内容只用于本次结果 sheet，不进入 event/metadata/checkpoint/日志/模型。生产 transport ephemeral、禁重定向/cookie/cache、有界读取/超时/取消。
4. Store 对 current Mission、Live 源、精确 artifact、已应用 clean 连接 fail closed；重复点击单请求，关闭/取消/配置或任务变化清理内容，旧响应不能污染新选择。成功/失败均不改任务、审批、receipt、envelope、session/event/artifact、checkpoint 或原健康状态。
5. compact/workbench 共享按需结果入口与父级 sheet；至少 44pt、VoiceOver/大字体/选择复制文本。只用原生 plain Text，不渲染链接、HTML 或自动执行。
6. 新增云端 XCTest、LogicSmoke 及真实 HTTP Gateway/Swift transport smoke，包含大/坏/越权/错身份/过期/容量/取消/stale/零副作用；保留所有旧断言、双平台构建/各 165 项基线/原生签名和实际截图门槛。
